# 時間割くん

中学校の時間割を直感的に作成・調整できるWebアプリです。React + Viteで構築されています。

## 特徴

- ドラッグ＆ドロップによる授業の配置・入替
- 自動生成（教員重複・会議コマ・連続授業上限・配置禁止時間などを考慮したスコア方式）
- 自動配置条件のカスタマイズ（教員の連続授業上限、同一教科の同日配置禁止、教科ごとの配置禁止時間、学年単位の教科固定、同時間配置禁止教科、主要5教科の分散配置など）
- 教員重複・会議コマ重複・連続授業超過などのエラー／警告チェック
- 学級ビュー／教員ビューの切替
- Undo / Redo
- CSV出力（Excel対応）、JSONファイルへの保存・読み込み
- ブラウザ内（localStorage）への一時保存

## データの扱いについて

このアプリは外部サーバーへの通信を一切行いません。入力したデータ（教員名・学級名・時間割情報など）は、お使いのブラウザのlocalStorage、またはお使いの端末に保存するJSONファイルにのみ保存されます。

## 開発

```bash
npm install
npm run dev      # 開発サーバー起動
npm run build    # 本番ビルド（dist/ に出力）
npm run preview  # ビルド結果のプレビュー
npm run lint     # ESLint
```
